# Лабораторная работа №3

Адаптивная страница техноблога «Инжектор Гаджет» для варианта 12.

В работе используются:

- Flexbox для навигации и карточек «Гаджеты недели»;
- CSS Grid для сравнения характеристик;
- раскладки 1/2/4 и 1/2/3 для разных размеров экрана;
- семантические теги `article` и `data`;
- медиазапросы для планшетов и смартфонов.

Для просмотра нужно открыть `index.html` в браузере.

Изображение смартфона: Samsung. Остальные фотографии: Unsplash — Klim Musalimov, Frank Septillion и Amjith S.
